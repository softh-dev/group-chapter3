## 第一次Git实验总结
1. git add 的作用是：将工作区的文件变更添加到暂存区，标记这些修改准备提交。
2. git commit 的作用是：把暂存区中的变更保存到本地Git版本库，生成一条带哈希标识的提交记录，仅保存在本地。commit 会记录文件改动、作者、时间、提交说明，形成版本快照；这个提交只存在你本机，不会自动上传 GitHub。你可以随时回退到这条提交对应的文件状态。
3. git restore notes.md 的作用是：使用版本库/暂存区里的文件，恢复覆盖工作区的notes.md，撤销工作区未add的修改。
commit 与 push 的区别是：- git commit：本地操作。将暂存区变更保存到本机 Git 仓库，只在你电脑生成版本记录，远端 GitHub 仓库完全看不到这次修改。git push：网络同步操作。把本地仓库已经 commit 完成的一系列提交记录，上传推送到 GitHub 远程仓库，团队其他成员拉取远端代码后，就可以看到你的提交。
